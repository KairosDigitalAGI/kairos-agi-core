# Kairos Coins

Sistema interno de progressão, sem blockchain. O contrato `FounderEconomy` contém saldo, XP, nível, meta do próximo nível e histórico de movimentações.

Saldo e histórico são mockados. A recompensa indicada nas missões ainda não altera um ledger persistente; essa ligação será feita quando o Task System receber uma camada de dados auditável.
