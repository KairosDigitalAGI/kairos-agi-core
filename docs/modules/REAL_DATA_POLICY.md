# Dados reais — política operacional

Exemplos financeiros, CRM, missões, XP, Coins e métricas sociais foram removidos da interface de produção. Não há agentes executando trabalho nesta aplicação; identidades configuradas aparecem aguardando executor. Fontes externas indisponíveis aparecem como travessão, não como receita zero.

Perfil informado pelo Founder: https://www.instagram.com/_kairosdigital_/ . O endereço não autentica a conta e não comprova métricas. Nenhuma API do Instagram foi consultada.

Editorial: chave atual `kairos.editorial.real.v1`. Na primeira leitura, registros próprios são preservados da chave antiga `kairos.editorial.v1`. IDs demonstrativos IG-001/002/003 e PR-001/002 ficam fora da nova visualização; a chave antiga permanece intacta, inclusive exemplos editados. Dados antigos corrompidos não são sobrescritos e não geram fallback fictício. Esse acervo pode ser recuperado manualmente do navegador; nenhum ZIP histórico foi importado.

Clone: sem semente. Contadores refletem apenas cadastros locais; referências e autorizações são declarações do Founder, não validação independente de arquivos. Sem dados comerciais de repositórios privados no frontend público. Fixtures antigas permanecem isoladas para testes e não são importadas pelo código de produção.
