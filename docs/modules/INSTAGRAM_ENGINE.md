# Instagram Engine

Este arquivo registra a versão demonstrativa da Missão 001. A implementação vigente é descrita em [Missão 002](INSTAGRAM_ENGINE_V0_2.md), com edição local, calendário, prompts e aprovações.

Apresenta indicadores mockados de alcance, engajamento, seguidores e produção mensal, além de um calendário editorial demonstrativo. O objetivo é validar a experiência operacional antes de conectar contas externas.

Não há autenticação, publicação, leitura de comentários ou chamada à API do Instagram no v0.1.
