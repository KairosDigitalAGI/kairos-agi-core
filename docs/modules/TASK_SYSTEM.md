# Task System

Representa trabalho como missões gamificadas com título, prioridade, XP, Kairos Coins, categoria, responsável e estado. A interface organiza as missões em Fila, Em execução e Concluídas.

Os botões Iniciar e Concluir atualizam o quadro durante a sessão. O estado ainda não persiste após recarregar a página; a futura camada de dados deverá preservar o mesmo contrato `Mission`.
