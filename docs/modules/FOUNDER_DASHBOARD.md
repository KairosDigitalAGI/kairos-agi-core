# Founder Dashboard

Painel inicial da Founder Edition. Consolida Receita Total, Receita Mensal, Leads Ativos, Clientes Ativos, Agentes Trabalhando, Ordens de Serviço e Missões Pendentes.

Os cards usam o contrato `Metric` e os dados de `src/data/mock`. O painel também mostra missões prioritárias, atividade dos quatro agentes, pulso de receita e progressão do Founder. Todos os valores são demonstrativos.
