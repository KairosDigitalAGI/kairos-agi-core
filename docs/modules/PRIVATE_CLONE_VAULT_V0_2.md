# Cofre privado de referências v0.2

O cofre do Studio guarda uma coleção de imagens por clone no IndexedDB do navegador. Cada referência tem nome, notas e estado de visualização protegido. O usuário pode adicionar, editar ou remover referências manualmente. O sistema não publica URLs, não replica arquivos para Vercel e não transfere imagens para providers. Dados criados na versão antiga, que possuíam uma imagem única, são migrados para uma referência local na leitura.

O dossiê baixável do episódio é um arquivo Markdown editorial com resumo, roteiro, falas, storyboard e prompts. Ele não representa um job, uma geração, cobrança ou autorização de publicação.
