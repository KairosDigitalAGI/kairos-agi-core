O estado operacional usa somente registros criados pelo Founder e dados derivados deles. Valores externos ausentes aparecem como indisponíveis. Não há banco, APIs sociais, WhatsApp ou armazenamento de segredos nesta versão. Clone e Instagram persistem metadados no navegador; o Video Engine processa arquivos no dispositivo e não os envia para servidores.
