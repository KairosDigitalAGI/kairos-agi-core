# Instalação segura

1. Copie o template para um repositório ou diretório específico da instalação.
2. Crie `.env` a partir de `.env.example` somente no servidor do tenant.
3. Configure armazenamento, auditoria e aprovação antes de habilitar canais.
4. Faça o pareamento oficial do mensageiro naquela instalação.
5. Teste entrada e rascunho; habilite envio apenas após aprovação definida.

Nunca copie uma sessão existente de WhatsApp, `.env`, banco, mídia ou logs para outra instalação.
